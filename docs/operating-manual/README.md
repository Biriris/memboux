## Source-of-truth hierarchy

For implementation facts, use this order:

1. Current source code and tests
2. Current migrations and deployment configuration
3. Accepted ADRs
4. Architecture documentation
5. Engineering and domain policies
6. General reference material

A document that describes an intended pattern does not prove that the pattern is already implemented.
