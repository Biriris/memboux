# Customer Lifecycle

## Current baseline

`Visitor -> Organizer -> Activated Event -> Returning Organizer -> Advocate`

## Approved direct wedding loop

`Visitor -> Self-service wedding draft -> Free activation or one-time premium purchase -> Guests contribute -> Archive/export -> Referral or another event`

## Approved professional wedding loop

`Professional applicant -> Verified professional -> Credit or subscription -> Wedding created -> Couple ownership accepted -> Guests contribute -> Wedding archived -> Capacity released -> Professional creates next wedding`

The consumer growth loop continues from the wedding:

`Couple or guest -> Memboux account -> Free non-wedding event -> New guests -> Future organizers`

The full direction, lifecycle invariants, metrics and rollout gates are in the
[Hybrid commercial model](HYBRID_COMMERCIAL_MODEL.md). These loops are approved
future behavior and are not evidence of current production behavior.
