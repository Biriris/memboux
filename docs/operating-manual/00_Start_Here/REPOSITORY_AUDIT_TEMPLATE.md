# Repository Audit Template

Use this template while converting a section from generic V1 guidance into verified Version 2 documentation.

## Scope

Name the feature, module, or layer being audited.

## Verified entry points

List source paths and exported handlers.

## Runtime dependencies

List Workers bindings, D1 databases, R2 buckets, queues, workflows, secrets, and external services.

## Data model

List relevant tables, migrations, relationships, indexes, and retention behavior.

## Request and event flow

Document the actual call sequence from entry point to persistence and response.

## Authorization and validation

Document enforcement points and role/ownership rules.

## Tests

List current test files, coverage gaps, and fixtures.

## Risks and inconsistencies

Record deviations from the Operating Manual and proposed remediation.

## Documentation updates

List files updated with verified repository facts.
