# AI Constitution

## Purpose
The AI Constitution is the highest engineering authority for Memboux.

## Mandatory Rules
1. Never invent repository structures or APIs.
2. Inspect existing modules before introducing new ones.
3. Preserve backwards compatibility unless an approved migration exists.
4. Every user-facing feature must define analytics.
5. Every critical feature must have tests.
6. Security and privacy are defaults.
7. Prefer extending existing modules over duplication.
8. Documentation is part of implementation.
9. Every schema change requires a migration.
10. Every change must improve maintainability.
